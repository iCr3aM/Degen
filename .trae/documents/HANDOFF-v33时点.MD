## 一、项目是什么

手机竖屏 H5 加密交易模拟游戏。玩家从 2013-01-01 带 $3,000 起步，在**真实历史小时线**上做多/做空/杠杆合约，
目标是活到 2024-12-31 收盘且权益越高越好。**唯一失败条件 = 权益归零。**

| 项 | 值 |
| --- | --- |
| 技术栈 | Vite 5 ＋ 原生 ESM，**无框架、无第三方运行时依赖、无后端** |
| 平台 | 仅手机竖屏 H5，整页不滚动 |
| 时间跨度 | 2013-01-01 ～ 2024-12-31（105,192 根小时 K） |
| 时间粒度 | **1 根 K 线 ＝ 1 游戏小时**；1x 速度下 1 游戏小时 ＝ 1 真实秒；**K 线内部另有 120 根 30 秒细刻度**（`TICK.perHour`） |
| 币种 | **5 个**：BTC / ETH / XRP / DOGE / SOL |
| 交易所 | **4 家**：Mt.Gox / Bitfinex / BitMEX / Binance（真实名称） |
| 数据成本 | **$0**（全部免费源，无需 API Key） |

### 架构（必须遵守的分层）

```
src/core/*    纯逻辑，零 DOM、零浏览器 API（可 headless 跑）
src/ui/*      只负责画，不含业务逻辑
src/main.js   唯一接线处（core ↔ ui 只在这里相遇）
tools/*       离线数据管线（Node 跑，不在游戏运行时里）
```

### 单一真相源

- **时钟：`s.i` ＝ 第几根小时 K（唯一刻度）**。1 游戏小时 ＝ 24 根真实小时？**不是** —— `s.i` 就是小时序号，一天 = 24 根。
- **存档版本：`STATE_VERSION = 10`**（key `localStorage.degen_save`）。
  > ⚠️ **本轮起不做存档兼容**（v26 拍板）：**`migrate()` 迁移链已整条删除**，`v !== STATE_VERSION` 的档**读到即丢弃、开新局**。
  > 版本轨迹（仅供追溯，已无迁移代码）：4 新增 `loaned`/`loan`/`pending` → 5→6 `chan` → 6→7 `impactOn`/`flow`/`godRuined`/`god`
  > → 7→8 `flow[sym]` 单池改逐笔列表（C1）→ 8→9 `seed`（S0）→ **9→10 `mode`（U1）＋ `consumed`（U2）**。
- **数据包：`public/data/<SYM>.bin` ＝ gzip**，**每根 17 字节** ＝ `[o, h−o, l−o, c−o]` int32LE（16B）＋ **尾 1 字节成交量份额**；
  再除一个每币固定的 `scale`；**不存时间戳**（`start + 序号 × 3600s` 推出）。
- **日流动性：`public/data/liq.bin` ＝ gzip(Float32)**，每日每币一个美元成交额（4,383 天 × 5 币，86 KB → gzip 63 KB）。
- **清单：`public/data/index.json`**（含 `liq` / `circulating` / `gapRanges`）。
- **价格位移唯一收口点**：`market.candleAt` 末尾 `const f = factorSource ? factorSource(sym, i) : 1;`，
  由 `main.js` 的 `bindFactorSource((sym, j) => factorFor(s, sym, j))` **注入**。**`f === 1` 时与数据包逐位相同**（离线断言的靠山）。

## 五、踩过的坑（**勿再重试**）

**本轮新踩（v33）**

- **`residualOfSide` 第一版返回带符号值（严重，被断言当场抓到）**：原写成 `return v;`，对砸盘（`dir = −1`）返回 −0.035，
  于是 `addFlow(-dir * back)` 写出的仍是**同向**一笔 ⇒ 位移不减反增（−3.5% → **−5.25%**）。
  **修法：`return dir * v;`（返回幅度，恒 ≥ 0），并在 JSDoc 写明「返回值是**幅度**」。** 教训：**凡「对折 / 返还款」类，
  先问自己返回的是幅度还是带符号值。**
- **衰减不对称 + 带符号求和 = 平仓弹回 / 过冲** —— 已用 A2（按残存值对折）＋ B1（正侧硬夹 50%）从数学上根除。
- **PowerShell 不支持 heredoc** ⇒ `git commit` 改用**多个 `-m` 参数**（不要用 `$(cat <<'EOF')`）。

**数据侧**

- **CDD 的 CSV 是最新在前，最早行情在最后一行** —— 验证早期数据必须读 tail。
- **CDD CSV 列序与表头写的相反**（2026-09-29 实测）：**`c[7]` ＝ 计价币成交额**、**`c[8]` ＝ 基础币数量**；`c[3..6]` ＝ OHLC。
- **Kraken 用老代号**：BTC ＝ `XBT`、DOGE ＝ `XDG`。
- **DOGE / XRP 的 2014–2017 段只有 BTC 计价**，美元价由 `币/BTC × BTC/USD` 换算。
- **XRP 序列里连续相同的 OHLC 是 Poloniex 对「无成交小时」的处理**（重复上一根），**不是数据造假**（占 12.7%）。
- **blockchain.com chart API 的 `start`/`end` 不可靠** ⇒ 拉 `timespan=all` 后本地按 `x` 过滤。
- **SOLUSDT 的 20 小时缺口**：Binance / Bitfinex / Kraken / OKX 都补不了 ⇒ 用 **Binance.US `SOLUSD`** 补。

**代码侧**

- `new Int32Array(nodeBuffer)` 会**逐字节复制** ⇒ 必须 `new Int32Array(raw.buffer, raw.byteOffset, raw.byteLength >> 2)`。
- **`main.js` 的 `lastDraw` 初值必须是 `-Infinity`（不是 `0`）** —— 否则读档到暂停态时界面永久停在骨架。
- **暂停 / 待决态下 `step()` 的 while 必须同时判 `s.over` 与 `s.paused`**（`checkRuin()` 是在循环内部把 `paused` 置真的）；
  `advanceOneHour()` 顶部闸门必须把 `s.pending` 一起挡住。
- **状态机里「暂停」落地后要保证还有一帧重绘** ⇒ `main.js` 需要 `loanDrawn` / `overDrawn` 这类标志 ＋ 强制 `force = true`。
- **`view.js` `clampRight` 曾把区间写反**（Batch 5 · B22 修）：`clamp(v.right, Math.min(a, maxRight), maxRight)`。
  **凡「左右边界」先自问哪一端是硬墙，别让 min/max 抢了方向。**
- **K 线槽宽必须按 `slots` 算、柱子右对齐**（`xAt(k) = (slots − n + k)·cw + cw/2`），否则首根会撑满整屏。
- **`1t` 细刻度桶必须不跨小时**（`tEnd = min(t0 + bucket − 1, hh·N + N − 1, right)`）—— 否则含针那一桶会盖住相邻小时，**针被抹平**。
- **构建目标必须 `es2020`**（`vite.config.js`）：`rng.js` 用 **BigInt 字面量**；S2 是第一个把 `simulate.js`（→ `rng.js`）拖进 bundle 的消费者。
- `browse_evaluate` / `browser_evaluate` 在本环境连续返回 `undefined` ⇒ **该环境不可用**。
- `.mjs` 顶层 `return` 需包进 `if (...) { ... }` 块。
