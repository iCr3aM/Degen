## 0 · 方法

**A. 无头审计靶场** —— `tools/sim-audit.mjs`（本轮新建）

核心层是**纯 JS、零 DOM**（`simulate.js` 文件头明示），因此可直接用 Node 驱动真实引擎、读真实数据包。
靶场三条纪律写在文件头：① 只读（不写文件、不进存档、不改 `src/`）② 走真实数据包 ＋ 真实引擎
③ 每节自报 ✓/✗，末尾总账，任何 ✗ 为发布阻塞项。**不进 `npm run build`。**

> 实现要点：fetch 打桩把 Vite 的 `./data/...` 重定向到 `public/data/...`；`bindFactorSource` 注入
> `god.factorFor` 位移；`mk()` 统一构造一局（建状态 → 设币/模式 → 载币 → 载 liq → 绑位移 → 定时刻 → tick）。

**B. 联网取证** —— 本轮 12 条基准，逐条对照（见 §2，来源见文末）。

**C. 范围**：下单全链路（开仓 / 平仓 / 强平 / 部分强平 / 资金费 / 借贷息 / OTC / 滑点 / 冲击 / NPC 级联）、
K 线与行情模型、UI / 手感 / 文案。

## 3 · 发现项

### F1 ✅ 已修 —— 靶场基准价口径错（非产品 bug）

第 8 节原以 `engine.markPrice`（标记价）当滑点基准，而 `openCheck` 成交价用的是
`exPrice(s, sym, s.ex)`（含各所 `dev.basis` 偏移）⇒ 2021/2024 出现「**负滑点**」（−0.0235% / −0.0070%）。
**修**：改为下单**前**取 `exPrice` 作基准（`pushFlow` 会写位移，之后取就含自己的永久冲击），
并新增「滑点对名义单调不减」断言。修后负值归零，**通过 83 · 失败 0**。

### F2 ⚠️ 待裁决 —— 滑点死区使「现代年大单」永不触发代价

把 `SLIP.threshold = 0.10` 翻译成人话：**单笔名义 ≥ 当日全市场成交额的 10% 才开始收滑点**。
锚点是**全市场**口径（§8.3 已定为设计），于是门槛被抬到单所盘口远够不着的高度：

| 年月 | 日流动性（全市场） | 触发门槛 = ×10% |
| --- | --- | --- |
| 2013-09 | $0.1M | $0.01M |
| 2016-06 | $82.5M | $8.3M |
| 2018-01 | $2,199.5M | **$220.0M** |
| 2021-04 | $10,806.4M | **$1,080.6M** |
| 2024-07 | $8,645.0M | **$864.5M** |

⇒ 实测：2018-01 / 2021-04 / 2024-07 连 **$100M** 的单都**零滑点**；只有 2013 / 2016 的大单触发（2016 $10M → 2.19%）。

- 按平方根律，$10M / 2021 的现实冲击 ≈ 0.09%（≈ $8.7K）——**量级小，但被记成 0**。
- 影响面：**手感**上「后期变成鲸鱼却感觉不到尺寸惩罚」；数值上单笔成本被系统性低估 ≤0.1%。

**可选修法**（请拍板，我不擅自改）：
| 方案 | 改动 | 效果 |
| --- | --- | --- |
| ① 降阈值 | `threshold: 0.10 → 0.01` | 2021 门槛降到 $108M —— 仍够不着，几乎无感 |
| ② 直连单所深度 | 分母改为「全市场 × 单所份额」 | 门槛降 1 个量级，最贴近现实，但**要新开一个度量**（违红线） |
| ③ 保持现状 ＋ 写口径注 | 不改代码 | 承认「本作不模拟微观盘口」，大单代价只在极早年体现 |

### F3 ⚠️ 待裁决 —— 杠杆通道维持线把 Bitfinex 规则套给了所有所

`maintRateAt(exId, notional, 'margin')` **恒返回 `MARGIN.maint = 0.15`**（不看 `exId`）。
但 Binance 杠杆（2019-07-11 起）真实维持保证金率是**分档的、低得多**（BTC 最低档 ≈0.5%）。
⇒ 3x Binance 杠杆多头的强平线：本作 **−18.3%**，现实 **≈−32.8%** —— **本作危险约 1.8 倍**。

- 若「杠杆＝危险、维持线一律 15%」是刻意的统一手感，则**保持 ＋ 补口径注**即可；
- 若要贴近现实，需给 Binance 加一张 margin 维持档表（与已有 `BINANCE_MARGIN_TIERS` 同范式）。

### F4 📝 记录 —— 资金费无 0.01%/8h 基准项

本作 `rate = clamp(k × clamp((longShare − 0.5)/0.5, −1, 1), ±max)`，**多空平衡时恰为 0**。
现实里利率项是**静息 0.01%/8h**（多头长期承担 ≈11%/年名义）。
⇒ 本作对**平衡市**的多头宽容了一点（少付 0.03%/日名义）。属可接受的简化，**不建议改**（改会全体变贵）。

### F5 📝 记录 —— 2013 锚按「全市场」当「单所深度」用

2013 锚 $564.5K/日 是 CoinLore 的**全市场**年均值，而 Bitfinex 单所 2013 年日量常达 $10M+。
⇒ 早年大单冲击被**高估**数倍。因早年玩家本金小（$1e3 量级），实际影响可忽略，**不建议改**。

### F6 ✅ 复核确认 —— A=2 与锚折扣

本轮独立复算，与 `NEXT-STEPS.MD` §8.2（`A = 2` 保留，明写为设计取值）／§8.3
（2017+ 统一 ×0.3）**结论一致**，无需返工。

### 阻塞项：**无**

| 无 look-ahead | σ 用**近 30 日已实现**日收益；`liqOf` 用当日；NPC 读「显示价剔除 NPC 自身」防自激 ✅ |

| 无副作用回归 | 未注入位移 / 未注入玩家量时，`candleAt` 与数据包**逐位相同**（离线断言靠此）✅ |
