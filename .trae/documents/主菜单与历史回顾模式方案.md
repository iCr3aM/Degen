## 2. 主菜单（进入游戏前）

**流程变更**：boot 完成后**一律先弹主菜单**，三个入口各自决定后续：

```
boot → mount → hideBoot() → openMenu()
   ├ 开始游戏 → 有档？二次确认 → createState() + wipe() + reload/重挂 → openIntro()（新手/老手）
   ├ 继续游戏 → clock.start()（读档续玩，不弹开场白）
   └ 历史回顾 → 进入回顾模式（第 3 节）
```

| 入口 | 可用条件 | 行为 |
|---|---|---|
| 开始游戏 | 永远可用 | 无档：直接开新局；**有档：按钮变「确认重开」（红）**，3 秒内再点才 `wipe()`，否则还原 |
| 继续游戏 | `load()` 非 `null` | 直接 `clock.start()`；**无档时整枚不出现**（LESS IS MORE：没有的选项不显示） |
| 历史回顾 | 永远可用 | 进入只读回顾模式；**不碰当前存档**，退出后回到主菜单 |

- 主菜单期间**时钟不启动**（与 `openIntro` 同一条：读完再开盘）。
- 「继续游戏」若读到的是一个 `s.over` 的档，照常进游戏并直接显示结束画面（现状行为，不改）。
- 三入口的 DOM 挂在 `#overlay`（`index.html` 已有该层），沿用 `openIntro` 的「无暗底」样式；按钮复用 `.act long / .act flat` 与 `.confirm-btns`。

## 3. 历史回顾模式（只回顾）

### 3.1 去掉什么（对照交易页骨架 `hud / symbols / chartWrap / posbar / logline / trade`）

| 块 | 处理 | 理由 |
|---|---|---|
| 操作区 `.trade`（金额 / 杠杆 / 速度 / 现货·合约 / 盘口 / 买卖 / 做多做空平仓） | **整块去掉** | 只读，不下单 |
| HUD 两格（账户权益 / 可用保证金） | **去掉** | 回顾没有账户 |
| 持仓条 `.posbar` | **去掉** | 回顾没有持仓 |
| 顶栏交易所切换器 `.exbtn` | **去掉** | 回顾不换所 |
| 底部 Tab 三页 | **去掉** | 只留一个回顾页 |
| 借贷遮罩 / 破产预警 / 上帝模式入口 | **不参与** | 回顾不判破产、无隐藏入口 |
| K 线图（`chart.js`） | **保留** | 复用的核心 |
| 币种条 `.symbols` | **保留（可点）** | 拍板 2：可切币，看各币上线时点也是历史的一部分 |
| 顶栏日期 | **保留** | 拍板 2：可切日期 |
| 日志条 `.logline` | **保留且加长** | 见 §3.6 |

> 顶上只保留两样：**日期 ＋ 播放/暂停**（外加「退出回顾」）。其余全清，界面只剩「K 线 ＋ 币种条 ＋ 日志」。

### 3.2 页面骨架与复用点

- `render.js` 的 `mount()` 新增一个 `.review-page` 分支（与 `.trade-page` / `.assets-page` / `.settings-page` 并列），`showPage()` 支持 `'review'`。
- **复用 `chart.js`**：`drawChart(canvas, opts)` 是纯 canvas 渲染器（吃 `candles / vols / slots / anchors / right / mark …`）。
  ⚠️ 目前**选项装配写在 `update()` 内部**（约 30 行）。为避免两处各写一份，本方案把这段抽成一个共享函数 `chartOpts(sym, view, refs)`，交易页与回顾页都调它 —— 这是本方案**唯一**要碰交易页渲染的地方，且是不改变输出的纯抽取。
- **复用 `market.js`**：`loadCoin` / `candleAt` / `volumeAt` / `rangeOf` 原样用。回顾态只需要 BTC 必有数据，其余币按懒加载拉（与现状一致）。
- **复用 `simulate.js`**：细刻度（捏合放大看针）在回顾里同样可用，无需额外工作。
- 回顾态放**模块级变量**（与 `tab` / `godTaps` 同口径），**不进 `s`、不进存档**。

### 3.3 时间轴 与 专属快进

- 回顾有自己的「时钟」概念：`s.i` 的**只读副本** `rv.i`（`0 → GAME.candles`）。它只是「看到第几根」，不驱动任何核心状态。
- 专属快进档：**`1x / 10x / 100x`**（不复用 `SPEEDS`，不污染正常玩法）。默认 `100x`。
  - `1x` 用于节点卡前后的「近距离看盘」；
  - `10x` 中速浏览；
  - `100x` 主巡航档。
- 「可切日期」＝ 顶栏日期可点开一个**日历 / 年份跳转**（跳转到某年某月一号），或在 K 线上拖动/双指缩放（复用 `bind.js` 的 `bindChart`）。

### 3.4 关键节点表

- 基座 = **现有 `anchors.js` 的 20 条**（BTC 为主，含 Mt.Gox / 减半 / 新冠 / 双顶 / Luna / FTX / ETF 等）。
- 补充 5 条（联网核对后，2013–2024 窗口内、现有表未收录的主线事件）：

| 日期（UTC 日粒度） | 标题（草） | 主题 |
|---|---|---|
| 2013-12-05 | 央行五部委发文，BTC 从 $1,200 崩落 | 监管 |
| 2017-09-04 | 七部委 ICO 禁令（「九四」） | 监管 |
| 2021-05-19 | 中国禁令 ＋ 特斯拉停收，BTC 单日 −30% | 监管 / 情绪 |
| 2021-09-07 | 萨尔瓦多把 BTC 列为法币 | 采用 |
| 2022-09-15 | 以太坊 Merge，ETH 转 PoS | 基建 |

- ⚠️ **只进回顾，不进 `anchors.js`**：`anchors.js` 被正常玩法的新闻 / 拥堵 / K 线刻度三处消费，往里加条目＝改正常玩法（新增 5 天新闻、其中两条带拥堵）。本方案新增的是**回顾专用表**（`review.js`），正常玩法一行不动。
  - ➜ 若你后续想让「九四 / 五一九」也进正常玩法的新闻，那是**另一个独立决定**，本方案不擅自做。

### 3.5 减速曲线 ＋ 节点卡 ＋ 跳过

**减速曲线**（`speedAt(i)`，纯函数）：

| 距下一个节点 | 速度 |
|---|---|
| > 1 游戏日 | 巡航档（默认 `100x`） |
| ≤ 1 游戏日 | `10x` |
| ≤ 6 游戏小时 | `1x` |
| 命中节点（`i === node.at`） | **暂停 ＋ 弹节点卡** |

**节点卡**（`.nodecard`，复用 `.confirm` 弹层范式）：

```
───── 节点卡 ─────
2014-02-25   Mt.Gox 被盗 85 万枚 BTC，停摆
（3–5 行史实说明：发生了什么 / 当时 BTC 在哪 → 到哪 / 市场后来如何）
[ 继续 ]  [ 跳过这个节点 ]
```

- 卡片期间**暂停**；`[继续]` 恢复巡航档；`[跳过这个节点]` 关闭卡片且**本节点不再弹**（记在「已看过」集合，只作用于本次回顾）。
- 另给一个全局 `[跳过全部节点]`（放在回顾页设置里），一键压到纯巡航 —— 对应「全跳 ≈ 17 min」。
- 「日志栏加长」与节点卡的关系：节点命中时**同时**把该节点的史实说明**推进回顾日志**（回顾日志只装节点与史实，不装玩家操作 —— 回顾没有玩家操作），卡片关掉后仍能在加长日志里回看。

### 3.6 日志栏加长

- 回顾页没有操作区（`.trade`）、没有 HUD、没有持仓条 ⇒ 固定块不必再守 431px 的账，省下的高度**全给日志**。
- 建议：日志条从 1 行 24px 扩到 **固定 6 行**（`144px`）常驻，或直接复用现成的 `openLog` 浮层做常驻面板；两者取一，实施时按实机高度定（届时可目视再调）。
- 回顾日志的**内容**：节点史实（点）+ 时间轴里程碑（如「ETH 上线」「SOL 上线」），带 `00:00 日期` 前缀与颜色 —— 直接复用刚落地的日志条样式（§20.10）。

## 4. 时长测算

`GAME.candles = 105,192` 游戏小时。

| 档位 | 纯巡航跑完 | ＋20 节点停留（各约 26 s） | 全跳节点 |
|---|---|---|---|
| 50x | 35.1 min | ≈ 43.8 min | 35.1 min |
| **100x（拍板）** | **17.5 min** | **≈ 26.2 min** | **17.5 min** |
| 200x | 8.8 min | ≈ 17.5 min | 8.8 min |

单节点成本 ≈ 24h÷10x(=2.4s) ＋ 6h÷1x(=6s) ＋ 阅读停留 ≈ 15s ⇒ **约 26 s**；20 个 ⇒ ≈ 8.7 min。

➜ 拍板 3 的「≈25 分钟」= `100x` 巡航 ＋ 20 节点。想快可点「跳过全部节点」压到 17.5 min，想慢可在任意时刻手动切 `1x/10x`。

## 6. 存档 / `STATE_VERSION` 口径

- **不动 `STATE_VERSION`（仍 11）**：
  - 主菜单是启动流程，不写状态；
  - 回顾态全部放模块级变量（`rv.i`、`speed`、`seen`），与 `tab` / `godTaps` / `liqMark` 同口径 —— 重开一局自然归零。
- 唯一会碰存档的是「开始游戏」（走现有 `wipe()` ＋ `disableSave()`），与 `doRestart` 同一条路，无新逻辑。

## 7. 验收口径

1. **正常玩法零变化**：`anchors.js` / `congestion.js` / 新闻态 / K 线刻度 —— 对照断言逐位不变（回顾补充表另存，不进 `anchors.js`）。
2. 回顾态**无任何下单入口**（操作区、HUD、持仓条、交易所键、Tab 均不在 DOM 里或不可见）。
3. `speedAt(i)` 单调：距节点越近越慢；`i === node.at` 必暂停。
4. 「跳过」只影响本节点（关掉卡片后，该节点不再弹；其余节点照旧）。
5. `chartOpts()` 抽取后，交易页 K 线**逐位相同**（同一份 opts 传入 `drawChart`）。
6. `npm run build` 通过；临时断言全绿后删除。

## 8. 实施顺序（建议分三批）

- **M1 · 主菜单**：`openMenu` ＋ 三入口 ＋ 开始游戏的二次确认 ＋ 「继续游戏」无档隐藏。（范围最小，先让入口可用）

- **M3 · 节点系统**：`review.js` 节点表、`speedAt` 减速曲线、节点卡、跳过、回顾日志。

每批各自 `git commit`（不 push）。
