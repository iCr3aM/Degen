## 二、音效 / 震动 / 动效深度优化

### 2.1 先回答「为什么震动感觉不到」（Android 实测结论，按可能性排序）

| # | 原因 | 证据 |
| --- | --- | --- |
| **a** | **绝大多数操作根本不震** —— `buzz()` 只在 7 个点被调用（日志事件、安全垫预警、结算、开/平仓）；而玩家日常的「切页 / 切币 / 点档位 / 换所」只走 `snd.tap()`，**没有震动** | [main.js:521-525](file:///f:/Cr3aM/Desktop/Degen/src/main.js#L521-L525)、[583-588](file:///f:/Cr3aM/Desktop/Degen/src/main.js#L582-L591)、[654](file:///f:/Cr3aM/Desktop/Degen/src/main.js#L650-L656)、[937-961](file:///f:/Cr3aM/Desktop/Degen/src/main.js#L930-L965) vs [687](file:///f:/Cr3aM/Desktop/Degen/src/main.js#L685-L690) |
| **b** | **弱档只有 12ms** —— 多数 Android 振动马达的有效最短时长约 20–40ms，12ms 常被驱动截断到感觉不到 | `VIB.light = [0, [12], [16,45,16]]`，[sound.js:108-111](file:///f:/Cr3aM/Desktop/Degen/src/ui/sound.js#L108-L111) |
| **c** | **连续 `navigator.vibrate()` 会互相取消** —— 新调用打断上一次的模式；当前**没有任何去抖/合并** | [buzz()](file:///f:/Cr3aM/Desktop/Degen/src/ui/sound.js#L121-L127) 直接透传 |
| **d** | `vibSupported()` 用 `matchMedia('(pointer: coarse)')` —— Android 开「桌面版网站」或接了鼠标时判定为 false，**设置页整行消失**，玩家以为坏了（`buzz` 其实还在跑） | [sound.js:98-103](file:///f:/Cr3aM/Desktop/Degen/src/ui/sound.js#L98-L103) |
| e | 系统层：手机「触摸振动 / 触感反馈」关闭，或省电 / 勿扰模式 —— 应用层无法绕过 | 说明性，不做代码处理 |

### 2.2 修法（sound.js ＋ main.js）

1. **让日常操作也有触感**：在 [dispatch()](file:///f:/Cr3aM/Desktop/Degen/src/main.js#L685-L690) 的通用 `snd.tap()` 处并挂一次 `buzz('light')`；切页 / 切币 / 换所 / 选档走 `pick` 级。
2. **加长可辨度**：`light` 由 `[12]` 提到 `[25]`；`heavy` 的 `[55,70,55]` 收紧为 `[50,60,50]`（三下节奏更易辨认）。
3. **加去抖 / 优先级合并**（照 `MARKET_GAP` 的既有做法）：~60ms 内的重复 light 合并为一次；`heavy` 可打断 `light`、`light` 不打断 `heavy` —— 解决「自我取消」。
4. **放宽能力探测**：`vibSupported()` 改为 `typeof navigator.vibrate === 'function' && (navigator.maxTouchPoints > 0 || coarse)`，让 Android 桌面版模式下也能看到这一行。
5. **设置页加「试一下」**：现有 [main.js:2034-2035](file:///f:/Cr3aM/Desktop/Degen/src/main.js#L2030-L2040) 只在选档时震一下，改为**一枚独立的自检按钮**（用加长模式），让玩家能确认硬件到底响不响。

### 2.3 新增音效（sound.js，全部振荡器合成，零资源，延续现有音色族）

| 新音 | 用途 | 现状问题 |
| --- | --- | --- |
| `tab` | 切页（交易/资产/设置） | 现在与普通点按同声，无差别 |
| `pick` | 选中：币种 / 杠杆档 / 交易所 / 粒度 | 同上 |
| `deny` | 操作被拒（开仓失败等） | 现在失败也走 `snd.tap()`，**与成功同声**，玩家分不出 |

（到账 / 买 U 已由 `notice` 兼任，不重复新增；`god` 开关音可选，若加则并入同批。）

### 2.4 新增动效（CSS，严守已有三条纪律）

三条纪律见 [style.css:1431-1439](file:///f:/Cr3aM/Desktop/Degen/src/ui/style.css#L1431-L1439)：**只动 opacity/transform/颜色**、**只在类切换处挂**、**reduced-motion 归零**。

| 新落点 | 做法 |
| --- | --- |
| 按钮按下态 | `:active { transform: scale(.97) }`，挂 `.act/.opt/.sym/.tab/.ic` —— 纯 transform，零布局成本 |
| 日志新行 | `.lg-row` 插入时 `slideIn`（opacity ＋ translateY） |
| 持仓条盈亏变化 | 值变化那一帧重挂 `.flash`（沿用总资产闪烁的既有做法，需 render.js 加变化签名） |
| 保证金率进区 | `safetyOf` 跌破阈值时一次脉冲（与 main.js 预警同源、同一帧） |
| 弹层出场 | `.out` 类 ＋ `animationend` 后再 `remove()` —— 现在关闭是瞬时移除（无出场） |

- 新增落点必须同时纳入 `.fx-low`（减弱）与 `.fx-off`（关闭）两条规则，并进 `prefers-reduced-motion` 块。
- ⚠️ **性能红线**：50x 下每帧预算；一律 opacity/transform，**绝不**动 `width/height/top`；按签名重建的节点（杠杆档 / 持仓列表 / 速度档）**不许挂基类 transition**（纪律②）。
- ⚠️ 手机端（<620px）布局是回归红线：只加动效、不改尺寸与排法。
