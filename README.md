# Degen ·《加密交易员》

一款以 **2013–2024 真实加密货币小时线**为底层的极简交易模拟游戏。手机竖屏 H5，打开即玩。

玩家带着 **$3,000** 从 2013-01-01 的 Mt.Gox 起步，在 12 年的时间轴上一路做多、做空、上杠杆，
唯一的失败条件是**账户权益归零**；活到 2024-12-31 收盘，权益越高越好。

`Vite 5` · 原生 ESM · **零框架、零运行时依赖、零后端** · 首包极小、运行时不依赖任何在线 API。

## 游戏内容

| 项 | 内容 |
| --- | --- |
| 时间跨度 | 2013-01-01 ～ 2024-12-31，共 **105,192 根真实小时 K 线** |
| 币种 | **BTC / ETH / XRP / DOGE / SOL**（各自在其真实第一根小时线出现的时刻开放） |
| 交易所 | **Mt.Gox / Bitfinex / BitMEX / Binance**（真实名称、真实开业与归零时间） |
| 初始资金 | $3,000（**USD 美元法币** —— 2013 年还没有 USDT；见「两格账本」） |
| 失败条件 | 账户权益归零（爆仓或资不抵债） |
| 胜利条件 | 存活至 2024 年底收盘结算，权益越高越好 |

**主要系统**

- **逐仓交易** —— 每个币一条独立仓位，不同币的多空可以同时持有；单仓爆仓只损失它自己的保证金，不等于破产。
  同一枚币已有仓位时可**加仓**（同向、同杠杆、同性质、同通道会**并进**那条仓位，入场均价按数量加权平均）
- **现货与合约** —— 操作区一键切换；现货走**融资**（1x 不会强平，加杠杆才会）、不付资金费，合约走完整强平逻辑
- **两格账本与买 U** —— 每个交易所的余额分 **USD 与 USDT** 两格：合约只认 USDT，现货先扣 USDT、不足的部分再扣 USD；
  平仓按当初扣款的比例**原路退回**。2014-11-20 起可在资产页**买 U**（溢价按 **27 条史实锚点**插值，可折价也可溢价 —— 2017-04 / 2018-10 那两年买 U 就是捡便宜）
- **资金曲线** —— 资产页顶部一张曲线图，对数纵轴，每游戏日采样一个权益点，一眼看清 12 年的资金轨迹
- **真实杠杆档位** —— **现货融资**与**合约**是两张独立的史实表，上限由**所选交易所 ＋ 年代**共同决定：
  Mt.Gox 仅 1x 无合约，Bitfinex 现货最高 10x / 合约 100x，BitMEX 无融资现货 / 合约 100x，
  Binance 现货 3x / 合约 125x（2021 后限 20x）
- **现货做空的史实闸门** —— 做空必须先借到币，只有该所此刻真的提供融资（上限 > 1）才开得出来
- **滑点** —— 按平方根定律计算成交价折让，分母是当日真实日流动性
- **资金费率** —— 合约持仓按 8 小时结算，随市况波动
- **订单冲击** —— 大单会真的推动后续行情，并在若干根之后衰减
- **网络拥堵与链上转账** —— 跨所搬钱不是瞬时的：按当时的网络拥堵程度等若干小时到账，
  金额够大还会自己把拥堵推高，让**下一笔**更慢
- **场外大宗（OTC）** —— 达到门槛后可以私下一口价建仓，代价是**溢价**（随年代与市况变化），
  且只能做现货 1x
- **历史锚点** —— 20 条真实历史事件（门头沟停摆、ICO 狂潮、新冠崩盘、FTX 破产……）以新闻与 K 线刻度呈现，
  **不产生任何人工涨跌幅**；新闻的涨跌幅从数据包**现算**（口径 D，事件走完才播报）
- **历史回顾模式** —— 主菜单里独立入口：不操作、不带 HUD，用 `1x / 10x / 100x` 巡航 45 条史实节点，
  命中即暂停弹卡（可开「自动跳过」）；按年份跳转，纯看历史
- **底部三页** —— 交易 / 资产 / 设置三条 Tab；切页即暂停，切回交易页自动续 `1x`
- **新手引导** —— 新局可选「我是新手」，6 步高亮指路（交易所 → 币种条 → 行情区 → 下单区 → 持仓条 → 底部 Tab）
- **日志与浮层** —— 底部日志条实时播报；点开是最近 30 条全文浮层，打开即暂停、关闭续玩
- **K 线缩放** —— `1 小时 / 1 日` 两档粒度，可拖动回看、捏合缩放、双击复位
- **存档** —— 自动落盘到 `localStorage`，随时关页续档

## 快速开始

需要 Node.js 18+。

```bash
# 安装依赖（只有一个 devDependency）
npm install

# 启动开发服务器（用手机视口 / 真机访问调试）
npm run dev

# 打包
npm run build

# 本地预览打包结果
npm run preview
```

### 重新生成行情数据包（可选）

仓库已预置 `public/data/`，**正常游玩不需要跑这一步**。若要重跑离线数据管线：

```bash
npm run data
```

`tools/fetch-data.mjs` 的额外开关：

| 开关 | 说明 |
| --- | --- |
| `--probe` | 只探测各数据源最早可用的时刻，不写入 |
| `--only=BTC,ETH` | 只处理指定币种 |
| `--from-cache` | 只用本地缓存，不联网 |

> Windows 上脚本会自动自举系统代理；设 `DEGEN_NO_PROXY=1` 可绕过。

### 浏览器要求

需要支持 `DecompressionStream`（2023 年起的主流移动浏览器均已覆盖）—— 数据包在客户端用 gzip 解压。

## 操作方式

- **开机** —— 整屏主菜单：**开始游戏 / 继续游戏 / 历史回顾**；新局可选「我是新手」启动分步引导
- **下单** —— 选币 → 选交易所 → 切「现货 / 合约」→ 选方向（多 / 空）→ 选金额档（1/4 · 1/2 · 全部）→ 选杠杆 → 开仓
- **平仓** —— 持仓条上的平仓键
- **时间** —— 顶栏暂停 / 速度档 `1x · 5x · 10x · 50x`（1x 下 1 游戏小时 ＝ 1 真实秒）
- **暂停** —— 只拦「会动钱」的动作（下单 / 平仓 / 换所 / 切通道），其余照常可用
- **K 线** —— 单指拖动平移、双指缩放；左上角小字切换 `1h` / `1d`
- **日志** —— 点底部日志条打开全文浮层（最近 30 条），打开即暂停、关闭续玩
- **底部 Tab** —— 交易 / 资产 / 设置；切页即暂停，切回交易页自动续 `1x`
- **资产页** —— 总资产（**USD / USDT 分格 ＋ 合计**）、资金曲线、**买 U**、持仓三组列表（普通现货 / 杠杆现货 / 合约）
- **设置** —— **音效**、**行情音**、**新手提示**、**涨跌色方向**（绿涨红跌 ⇄ 红涨绿跌）四个开关，以及重开本局（带二次确认）
- 界面**整页不滚动**，所有元素服务于快速下单与持仓监控：手机竖屏是**单列纵向布局**，
  窗口宽到 900px 以上则交易页改为**双栏**（左列行情、右列操作区），620–899px 只放宽容器宽度

## 技术栈

| 项 | 说明 |
| --- | --- |
| 构建 | Vite 5（构建目标 `es2020`） |
| 语言 | 原生 JavaScript（ESM），无 TypeScript、无框架 |
| 渲染 | Canvas 2D 画 K 线；DOM 只负责 UI |
| 依赖 | 运行时**零依赖**；`vite` 是唯一的 devDependency |
| 平台 | 移动端竖屏优先的 H5（手机浏览器 / 微信 WebView）；桌面浏览器可玩（交易页宽到 900px 自动转双栏），不做原生 App |

## 项目结构

```
src/
  core/            纯逻辑层 —— 零 DOM、零浏览器 API，可 headless 运行
    config.js        全局配置唯一真相源（币种 / 交易所 / 速度 / 杠杆 / 费用 / OTC）
    state.js         状态结构与默认值、日志
    engine.js        时间推进、开平仓、强平、破产、换所
    market.js        行情与日流动性的懒加载
    positions.js     逐仓持仓：保证金、强平价、资金费率
    impact.js        滑点（平方根定律）与合成盘口成交
    simulate.js      小时内部的细粒度价格路径
    rng.js           确定性随机数（哈希式，无状态）
    congestion.js    网络拥堵、转账到账
    anchors.js       历史锚点表（唯一真相源）
    god.js           订单冲击（价格位移层）
    save.js          localStorage 落盘与续档
    format.js        数值与价格格式化
  ui/              只负责画，不含业务逻辑
    render.js        DOM 渲染（HUD / 持仓条 / 操作区 / 弹层）
    chart.js         Canvas 2D K 线
    view.js          视野、缩放、粒度
    bind.js          事件绑定
    sound.js         音效（Web Audio 合成，零音频文件）
    style.css        全部样式
  main.js          唯一接线处（core ↔ ui 只在这里相遇）
tools/
  fetch-data.mjs   离线数据管线（Node 跑，不在游戏运行时里）
public/
  data/            预置行情数据包（见下）
```

## 架构约定

1. **分层不许破** —— `src/core/*` 不碰 DOM，`src/ui/*` 不含业务逻辑，两者的唯一交汇点是 `src/main.js`。
2. **单一真相源** —— `config.js` 是配置的唯一出处；`s.i`（第几根小时 K）是时间的唯一刻度。
3. **数字口径** —— 币种费率、杠杆档位、解锁时间等全部按史实设定，**不要凭记忆改数字**，改动前先查文档出处。
4. **数据不合成价格** —— 五个币全部使用真实小时线，不做日线插值、不做平线补齐。

## 数据说明

`public/data/` 全部为预置静态文件，**按需懒加载**（没看过的币不下载）：

| 文件 | 格式 |
| --- | --- |
| `<SYM>.bin` | gzip 压缩，每根 **17 字节**＝ `[开, 高-开, 低-开, 收-开]` × int32LE ＋ 1 字节成交量份额；再除以每币固定的 `scale`。**不存时间戳**（由起始时刻 ＋ 序号 × 3600s 推出） |
| `liq.bin` | gzip 压缩的 Float32，**每日每币一个美元成交额** |
| `index.json` | 清单：币种元信息、时间范围、编码方式、来源统计 |

数据来源优先级：`Bitstamp → Bitfinex → Binance → Binance.US（仅补 SOL 缺口）→ CryptoDataDownload → Kraken 归档（备查/校验）`；
后一个源只补前面留下的空洞，绝不覆盖。全部取自免费公开源，**无需 API Key**。
